# Digital Clock Application ⌚

Bu proje, **C#** ve **Windows Forms** kullanılarak geliştirilmiş, sistem saatini gerçek zamanlı olarak ekrana yansıtan bir dijital saat uygulamasıdır.

## 🚀 Proje Hakkında
Uygulama, Windows Forms içerisindeki `Timer` bileşeninin kullanımını ve zaman verilerinin (`DateTime.Now`) formatlanarak arayüze (Label) aktarılmasını demonstre eder.

## ⚙️ Özellikler
* **Canlı Zaman Gösterimi:** Saniye hassasiyetinde güncellenen saat.
* **Tarih Bilgisi:** Gün, Ay ve Yıl bilgisinin gösterimi.
* **Timer Mekanizması:** Arka planda çalışan zamanlayıcı ile arayüzün anlık yenilenmesi.
